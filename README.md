# LSTM Next Word Predictor

## About

This project uses a Long Short-Term Memory (LSTM) neural network to predict the next word in a text sequence.

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Natural Language Processing (NLP)
* Google Colab

## How It Works

1. Collect and preprocess text data.
2. Tokenize the text into sequences of integers.
3. Apply padding to make input sequences equal in length.
4. Train an LSTM model to predict the next word.
5. Generate text by repeatedly predicting the next word.

## Model Architecture

* Embedding Layer
* LSTM Layer
* Dense Layer with Softmax Activation

## Future Improvements

* Train on a larger and more diverse dataset.
* Improve prediction accuracy.
* Experiment with different model architectures.
